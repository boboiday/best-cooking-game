Dapur Kilat — a timed order cooking game. You run a small Indonesian warung kitchen: read the order board, stack each dish's three ingredients in the right order, and serve before the timer runs out. Serve 10 dishes in a 3-minute shift to win; 3 lost orders closes the kitchen.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080 in a desktop browser
```

Controls: click an ingredient (or press 1–5) to add it to the plate, S to serve, X to clear the plate, click an order card to select it.
